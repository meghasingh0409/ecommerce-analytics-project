# 🛒 Olist E-Commerce Analytics Project

## 📌 Overview
End-to-end data analytics project analyzing 
99,441 orders from Brazilian e-commerce 
platform Olist (2016-2018).

## 🛠️ Tools Used
| Tool | Purpose |
|------|---------|
| Python (Pandas) | Data Cleaning |
| SQL Server | Business Queries |
| Power BI | Dashboard |
| Excel/Power Query | Initial Analysis |

## 📊 Dataset
- Source: Kaggle - Brazilian E-Commerce by Olist
- 99,441 orders | 9 tables | 2016-2018

## 💡 Key Findings
- 💰 Total Revenue: R$ 16.01 Million
- 📦 Total Orders: 99,441
- ⭐ Avg Review Score: 4.09/5
- ⚠️ Late delivery drops review score by 47%
- 🏆 Health & Beauty = #1 revenue category
- 📍 SP state = highest sales region
- 💳 Credit card = 78% of payments
- 📈 Business grew 27x from 2016 to 2017

## 📁 Project Structure
- notebooks/ → Python data cleaning code
- sql/ → 10 business SQL queries
- dashboard/ → Power BI screenshots
